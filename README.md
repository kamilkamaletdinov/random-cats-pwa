# Случайные котики — PWA для iPhone

Веб-приложение показывает случайные фотографии кошек. Его можно добавить на домашний экран iPhone через Safari.

## Как запустить

1. Разместите содержимое этой папки на любом HTTPS-хостинге.
2. Откройте адрес сайта в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран „Домой”» → «Добавить».
4. Откройте приложение с домашнего экрана.

Для установки полноценного PWA нужен HTTPS-адрес. Обычный `http://` подойдёт только для простой проверки в браузере.

## Быстрый хостинг через Netlify

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите папку `cat-pwa` в окно сайта.
3. Скопируйте выданный HTTPS-адрес и откройте его на iPhone.

## Проверка на компьютере

Откройте терминал в папке `cat-pwa` и выполните:

```bash
py -m http.server 8080
```

Затем откройте <http://localhost:8080>.

## Как это работает

- При запуске приложение выбирает случайную фотографию через The Cat API.
- Кнопка «Ещё котик» загружает следующую случайную фотографию.
- Если основной API недоступен, используется резервный источник cataas.com.
- Service Worker сохраняет оболочку приложения для запуска без интернета.
