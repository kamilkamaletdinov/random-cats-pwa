# Случайные котики — PWA для iPhone

Веб-приложение показывает случайные фотографии кошек и устанавливается на домашний экран iPhone как отдельное приложение.

**Опубликованный адрес:** <https://kamilkamaletdinov.github.io/random-cats-pwa/>

## Установка на iPhone

1. Откройте [приложение в Safari](https://kamilkamaletdinov.github.io/random-cats-pwa/).
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой).
3. Выберите «На экран „Домой”».
4. Нажмите «Добавить» и откройте иконку «Котики» с домашнего экрана.

Для установки и полноценной работы PWA используется HTTPS-адрес.

## Проверка на компьютере

Откройте терминал в папке `cat-pwa` и выполните:

```bash
py -m http.server 8080
```

Затем откройте <http://localhost:8080>.

## Как это работает

- Вкладка «Фото» выбирает случайную фотографию через The Cat API.
- Вкладка «GIF» загружает случайный анимированный котик через cataas.com.
- Кнопка под картинкой загружает следующий случайный фото или GIF.
- Если основной API для фотографий недоступен, используется резервный источник cataas.com.
- Service Worker сохраняет оболочку приложения для запуска без интернета.
